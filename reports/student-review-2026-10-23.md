# Проверка самостоятельного чтения ТРЗБД

История первого прохода. Повторная проверка выявила скрытую прокрутку и недостающие шаги выполнения; актуальные исправления — [здесь](independent-reading-second-pass.md).

Редакция `trzbd-2026.10.23-student-review-r12`. Проверены объяснения 13 лекций и 104 исходных вопросов: определения, механизм, причинные переходы, примеры, практические действия и задания. Это редакционная проверка с позиции студента, а не апробация с реальной группой и не сверка с недоступной РПД.

## Содержание

- Полный ход 138 разборов SQL, таблиц, ER-фрагментов и схем вынесен из преподавательских пояснений на самостоятельные экраны после соответствующего примера. Прежние 125 отображений примеров сохранены. Обращения к преподавателю заменены объяснением результата для студента.
- Для каждой лекции названы предпосылки и переход от предыдущей темы. Итоговые слайды связывают выводы темы вместо повторения восьми полных записей в тетрадь. Определения и правила остаются перед объяснением.
- Развёрнуты короткие переходы: принадлежность свойства, направления кратности, отличие кода от id, назначение PK/UNIQUE, изменённый CSV, судьба дубля, ON и WHERE, пути эффективных прав. В определениях FK, сироты и COUNT устранено двусмысленное «ненулевой»: речь о значении, отличном от NULL; число 0 учитывается COUNT.
- Все 104 кейса используют действия, промежуточные состояния и практический итог. Убраны обязательный прогноз, выбор оцениваемого варианта и кнопка проверки решения. Отдельные четыре формата самопроверки остаются — 416 заданий.
- Изменяемые варианты JOIN меняют пары и агрегаты. VIEW повторно читает изменённый набор; произведение двух дочерних отношений исправляется отдельной агрегацией. В транзакции различаются UPDATE, автоматически вызванный триггер, исход INSERT и общий COMMIT/ROLLBACK. SQL триггера обозначен как его тело, RESIGNAL — как действие обработчика.
- Мини-набор кейса задаёт собственные имена и значения: их нельзя смешивать с id общего стенда. В браузере моделируются подготовленные случаи; выполнение произвольного SQL не заявляется.

## Оформление и комплект

Исправлены поля схем загрузки: количество строк и описание входа больше не выданы за столбцы таблицы. Поля и ограничения различимы, карточки выровнены, стрелки привязаны к соответствующим таблицам. В режиме преподавателя высота освобождена за счёт отступов, без уменьшения подписей. Окно аудитории прокручивается к текущему действию кейса. Сохранены Raleway, фирменные ресурсы, обе темы, исходный порядок вопросов и оформление эталона.

README содержит названия лекций по семестрам. Речь обновлена для всех лекций: один `.teacher.md` на тему, без `.presenter.md`. Убраны служебные вставки из учебного текста. Проверено авторство Git: авторы и коммитеры соответствуют настроенной учётной записи пользователя; история не переписывалась. Из PNG удалены встроенные сведения о создателе; пиксельные данные сохранены.

## Проверки и границы

Структура: 13 лекций, 1411 экранов, 104 вопроса и определения, 416 заданий. 948 существующих ID сохранены; 26 объединённых страниц литературы доступны через перенаправления, все 1495 прежних ссылок разрешаются. Число экранов фиксирует состав, а не доказывает качество.

Проверки TypeScript, lint, сборки и отделения преподавательских данных выполнены отдельно. 57 unit-проверок, 19 браузерных сценариев, включая все кейсы, 24 исполняемых SQL-сценария MySQL 8.4.13. Исполнение всех 104 SQL-фрагментов не заявляется. Для процедур, прав и резервирования сохранены отдельные отчёты предыдущих проверок. 13 карт преподавательского комплекта сверены с SHA-256 текущего course.json; 13 скачиваемых текстов побайтово совпадают с каноническими файлами.

Геометрия проверяется для всех экранов в обычном просмотре и панели преподавателя, отдельно — печатные рамки без создания PDF и мобильные схемы обеих тем. Конкретные итоги находятся в `student-layout-verification.json` и выводе браузерных проверок.

Технические основания уточнений сверены с документацией MySQL 8.4: [ошибки InnoDB](https://dev.mysql.com/doc/refman/8.4/en/innodb-error-handling.html), [роли](https://dev.mysql.com/doc/refman/8.4/en/roles.html), [обработка VIEW](https://dev.mysql.com/doc/refman/8.4/en/view-algorithms.html). Реальный темп занятия и понимание группой остаются предметом апробации.
