# МДК.11.01 Технология разработки и защиты баз данных

Лекции 4 курса. Данные — `public/course.json`, определения и предметные модели — `public/learning.json`. Текущая редакция: `trzbd-2026.10.23-database-cases-r9`. Проверка базовой схемы использует `@olgakraven/lecture-engine`; просмотр, каталог, кейсы и два окна реализованы в `src/`.

Сохранены 13 исходных тем, их названия, порядок, компетенции и часы: 7 семестр — 7 тем и 20 лекционных часов; 8 семестр — 6 тем и 18 часов. Эти сведения перенесены из исходной конфигурации; повторная сверка с официальным документом не выполнена, поскольку файл РПД по указанному пути недоступен.

Сохранены исходные названия и порядок 104 вопросов. У каждого — определение перед объяснением, разобранный пример, отдельный кейс с конкретными данными и четыре осмысленных формата самопроверки: один ответ, несколько, короткий ответ, соответствия. Всего 416 заданий и 1273 слайда. Библиография сгруппирована по два источника; 26 объединённых страниц имеют перенаправления, 948 прежних ID сохранены. Добавлены 312 страниц самопроверки и 13 схем объектов и зависимостей перед вопросами темы. Все 125 отображений исходных примеров, SQL, таблиц и ER-фрагментов и полные правила сохранены.

Все 104 кейса имеют собственные таблицы, поля, связи либо маршрут проверки, операцию и причинный вывод. В режиме показа кейс открывается в текущем окне и синхронизируется с аудиторией. Прогноз и обоснование не транслируются; итог открывается отдельной командой. Схемы поддерживают ручные шаги, анимацию, паузу и уменьшенное движение.

## Заметки и показ

Заметки включены в проект: `public/teacher-notes.json`. При открытии панели преподавателя они загружаются автоматически без импорта и пароля; локальные правки сохраняются поверх встроенного сценария. Это открытые учебные подсказки по прямому выбору пользователя. Окно аудитории сценарий не запрашивает. Ключи самопроверки хранятся отдельно в `public/assessment.json`; режим предназначен для обучения.

Прежние локальные правки сценария переносятся по ID с проверкой отпечатков исходных полей; обновлённый базовый текст не заменяется старой неизменённой копией. Личные заметки хранятся отдельно. Ответ и его объяснение передаются окну аудитории только по явной команде преподавателя.

## Команды

```sh
npm ci
npm run dev
npm run lint
npm run typecheck
npm run test
npm run validate:content
npm run check:teacher
npm run build
npm run check:privacy
npm run test:e2e
node scripts/verify-learning.mjs
npm run export:pdf -- --out outputs/pdf/student
npm run check:pdf -- outputs/pdf/student
```

Для экспорта одной лекции добавьте `--topic ID`. PDF создаётся из печатного представления сайта, без ответов и сценария. Для семестра/года доступны штатные действия печати в интерфейсе. Сценарий в Markdown и TeacherPack сохраняется отдельно в преподавательском комплекте.

Исходные данные до миграции сохранены в `authoring/legacy-course.ts` и `authoring/legacy-deck.ts`. Генератор `authoring/migrate.mjs` одновременно формирует слайды, сценарий, задания и карту переноса. Повторная генерация заменяет сгенерированные файлы: прежде экспортируйте ручные правки и сверяйте их с новой версией. Исторические исходники в `src/data` и `src/deck` не используются опубликованным проигрывателем.

## Проверки и ограничения

Текущий итог — `reports/reference-review-2026-10-23.md`, карта 104 вопросов — `reports/adequacy-map-2026-10-23.json`. Unit 57/57, E2E 19/19: обе попытки и предметные данные всех кейсов, четыре формата заданий, два окна, явное раскрытие, переключение сценария, перенос заметок и скачивание текста. Все 1273 печатных кадра и 658 экранов с заданиями, примерами и схемами помещаются в границы. При ширине 320 выполнены 273 проверки отображения, включая все 104 паспорта и 104 кейса; горизонтального переполнения нет. Новые SQL-примеры прошли 20 проверок в отдельном MySQL 8.4.13. Прежние 42 проверки базового стенда и восстановления зафиксированы в предыдущем отчёте; SQL стенда в этой правке не изменён. PDF не создавались; проверка печатного DOM не равнозначна проверке PDF. Официальная РПД, физический проектор и реальный хронометраж остаются вне подтверждённой проверки.

Сохранён шрифт Raleway: основной текст 400, кнопки 600, заголовки 700. Переносимый CSS — `public/fonts/raleway-profile.css`, шрифт — соседний `raleway-cyrillic.woff2`; код использует Consolas / Courier New.

Для локального скачивания преподавательских Markdown задайте переменную `TRZBD_TEACHER_DIR` с каталогом единственных `.teacher.md` до запуска Vite. Middleware читает эти файлы напрямую, не копируя их в публичную сборку. Для обновления текстов используйте `node scripts/build-priority-teacher.mjs --all --out PATH`. После изменения авторских случаев выполните `npm run migrate`; карту отпечатков прежней редакции заметок создаёт `node scripts/build-note-compatibility.mjs`.
