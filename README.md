# Технология разработки и защиты баз данных

## 7 семестр

- Комплект исходных данных для разработки базы
- Перечень таблиц по комплекту исходных данных
- Реализация согласованного перечня таблиц
- ER-диаграмма реализованной базы
- Подготовка файлов и загрузка данных
- Проверка загрузки и скрипт поставки
- Контрольные запросы по загруженным данным

## 8 семестр

- Представления по загруженной базе
- Согласованное изменение загруженных данных
- Индексы полей поиска загруженной базы
- Разграничение доступа к загруженной базе
- Резервное копирование и защита комплекта
- Сборка комплекта результатов
