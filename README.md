# МДК.11.01 Технология разработки и защиты баз данных

Лекции 4 курса на общем движке `@olgakraven/lecture-engine` версии `0.2.1-uiabd.1`. Данные курса — `public/course.json`. Содержательная редакция всех 13 лекций: `trzbd-2026.10.22-content-all-r4`.

Сохранены 13 исходных тем, их названия, порядок, компетенции и часы: 7 семестр — 7 тем и 20 лекционных часов; 8 семестр — 6 тем и 18 часов. Эти сведения перенесены из исходной конфигурации; повторная сверка с официальным документом не выполнена, поскольку файл РПД по указанному пути недоступен.

Сохранены все 104 вопроса в 13 темах. Всего 974 слайда и 104 самостоятельных случая с последующим разбором. Вместо четырёх однотипных проверок каждого вопроса используется задача на применение; в курсе сохранены все четыре поддерживаемых формата ответов. Исходные данные, объяснения, ER-фрагменты, промежуточные результаты и преподавательский текст связаны с конкретными слайдами.

## Заметки и показ

Заметки включены в проект: `public/teacher-notes.json`. При открытии панели преподавателя они загружаются автоматически без импорта и пароля; локальные правки сохраняются поверх встроенного сценария. Это открытые учебные подсказки по прямому выбору пользователя. Окно аудитории сценарий не запрашивает. Ключи самопроверки хранятся отдельно в `public/assessment.json`; режим предназначен для обучения.

Редактор содержания использует стандартный вход шаблона. Его настройки отделены от подсказок преподавателя. Инструкция с реквизитами входа не включена в репозиторий.

JSON-карты и частичные TeacherPack служат проверке и панели, а не второй текстовой копией.

## Команды

```sh
npm ci
npm run dev
npm run lint
npm run typecheck
npm run test
npm run validate:content
npm run check:teacher
npm run build
npm run check:privacy
npm run test:e2e
npm run export:pdf -- --out outputs/pdf/student
npm run check:pdf -- outputs/pdf/student
```

Для экспорта одной лекции добавьте `--topic ID`. PDF создаётся из печатного представления сайта, без ответов и сценария. Для семестра/года доступны штатные действия печати в интерфейсе. Сценарий в Markdown и TeacherPack сохраняется отдельно в преподавательском комплекте.

Исходные данные до миграции сохранены в `authoring/legacy-course.ts` и `authoring/legacy-deck.ts`. Генератор `authoring/migrate.mjs` одновременно формирует слайды, сценарий, задания и карту переноса. Повторная генерация заменяет сгенерированные файлы: прежде экспортируйте ручные правки и сверяйте их с новой версией. Исторические исходники в `src/data` и `src/deck` не используются опубликованным проигрывателем.
