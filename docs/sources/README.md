# Метаданные источников

Публичная папка содержит только метаданные. Полные РПД, учебный план и электронные версии книг автоматически не копируются.

Машиночитаемый реестр: `src/data/sourceRegistry.ts`.

Человекочитаемый реестр: `SOURCES.md`.

Правила проекта:

- технические утверждения связываются со `sourceIds`;
- исполняемые примеры используют синтаксис MySQL 8.4;
- PostgreSQL и PL/pgSQL упоминаются только как явно маркированное пояснение литературы;
- дата проверки онлайн-источников — 31.08.2026;
- локальные пути к РПД и учебному плану фиксируются без публикации исходных файлов.
