# Разработка и проверка курса

Учебный каталог — в корневом README. Содержание хранится в public/course.json, определения, схемы и практические разборы — в public/learning.json. Исходники содержательных правок — в authoring/; JSON воспроизводится через npm run migrate.

Проверки: npm run lint, npm run test, npm run build, npm run check:privacy, npm run test:e2e, node scripts/verify-learning.mjs. Для выполнения SQL используется отдельный MySQL и scripts/verify-*-sql.mjs.

Локальный просмотр: npm run dev -- --host 127.0.0.1 --port 5194 --strictPort. Текущая работа сохраняется в ветке codex/trzbd-content-all; внешнее развёртывание выполняется отдельно.

В кейсах последовательные действия меняют учебные состояния таблиц и результат операции. Прогнозы, оцениваемый выбор и проверка ответа в этом режиме отсутствуют. Самопроверка лекции отдельно сохраняет четыре формата заданий. Браузер моделирует подготовленные случаи; выполнение произвольного SQL в нём не заявляется.

Тексты преподавателя создаёт scripts/build-priority-teacher.mjs --all --out ПАПКА. Канонический комплект хранится в BrainM: одна .teacher.md на лекцию, карты выравнивания и пакеты панели в _support/. TRZBD_TEACHER_DIR указывает серверу папку для скачивания. Заметки панели открыты по выбранному учебному режиму; окно аудитории сценарий не загружает.

Текущий отчёт — reports/student-review-2026-10-23.md, карта вопросов и машинные отчёты рядом с ним. Прежние отчёты описывают свои этапы. Учебные PDF и архивы на этом этапе не создаются. Официальная РПД по ранее указанному пути недоступна; соответствие ей не заявляется.
